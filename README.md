# 仙阙凌霄 · 虚实共生 VR 数字展厅与沉浸式交互系统

> **毕业设计综合成果 / 跨端 VR 数字展厅系统**  
> 支持 WebXR 纯网页沉浸、手机陀螺仪/双目立体分屏、以及虚幻引擎 5（Unreal Engine 5.7）原生客户端 VR 体验。

---

## 效果预览与设计对照

本项目严格按照任务要求与参考图标准完成高精度数字展厅构建：
- **从白模到完整 PBR 仙阙**：针对原始工程中的未贴图白模，系统性完成 4 通道 PBR 材质装配与 3D 纹理烘焙，真实呈现八角飞檐金顶宝顶、三层汉白玉立柱雕花、八面青翠玉门金窗，以及浮空仙台上的 16 瓣金线莲花如意曼陀罗地纹。
- **环绕建筑体积云海**：在建筑与浮空台周身及底部布置多层软粒子体积云团，支持根据「仙阙晴光 / 晚霞流金 / 紫霄夜境」天色光照动态自适应变色与呼吸浮动。

## 核心技术实现细节

### 1. 资产逆向解码与正向物理烘焙管线
- **底层解压缩与解码**：自主研发 Oodle Kraken 流式解压与 UE 5.7 `TSCF_UEDELTA` 差分编码还原算法，从二进制 `.uasset` 物理文件中完整解出 16 张 4096×4096 原始贴图与原生几何体。
- **法线与面绕序纠偏**：排查并修复了几何转换过程中的三角形绕序问题，修正了正面法线朝向，杜绝了 WebGL 背面剔除导致的几何体镂空与暗影异常。
- **几何导向的曼陀罗纹理烘焙**：通过 UV 三角形三维重投影与极坐标纹理合成算法，将原为纯白模的浮空平台台面，高保真合成为带有 8 瓣/16 瓣金线莲花如意纹的汉白玉地坪，并同步将其微观坡度烘焙进法线贴图，使斜射日光能在地纹边缘产生自然生动的立体明暗交界线。
- **物理光泽平衡**：将金属度校准至物理合理的区间，确保金属饰件金光灿然的同时，白玉石柱与地面保持温润素雅的散射光泽。

### 2. 环绕建筑体积云系统
- 采用面向相机自动对齐的径向软云粒子簇，在仙阁四周与浮空平台下方构建起连绵起伏的仙海云涛。
- 云层受全局天色光照系统同步控制，在「仙阙晴光」下呈现纯白微金的透光卷云，在「晚霞流金」下呈现琥珀暖光，在「紫霄夜境」下呈现幽蓝银辉。

## 本地启动与使用指南

### 方案 A：Web 端免安装极速体验（推荐）

1. **启动服务**（二选一）：
   - 若本地已安装 **Node.js**：
     ```bash
     cd vr_digital_showroom
     node server.js
     ```
   - 若本地只有 **Python 3**（无需安装任何第三方库）：
     ```bash
     cd vr_digital_showroom
     python3 server.py 8080
     ```
2. **体验展厅**：
   - 打开浏览器访问：`http://localhost:8080`
   - **天色切换**：点击右上角「仙阙晴光 / 晚霞流金 / 紫霄夜境」按钮，实时查看动态天光渲染。
   - **展品导入测试**：点击顶部「导入测试资源」，可上传 `.glb` 模型或宣传画，系统会自动放置在浮空台中心。
   - **留言留痕**：点击「留言互动」展开留言簿；点击右侧工具栏的「图钉」图标，再点击场景中的任意建筑或台面，即可在真实三维坐标处留下您的点评。
   - **多端体验**：
     - 手机端直接扫码或在同局域网浏览器中输入内网 IP 访问；
     - 点击底部「手机陀螺仪」开启体感感知；
     - 点击「手机 VR 双目分屏」戴上 VR 眼镜盒观看立体分屏；
     - 使用 Oculus / Pico 等 VR 头显内置浏览器打开网页，点击「VR 头显入镜」即刻体验 6-DoF 沉浸漫游。

---

### 方案 B：Unreal Engine 5 原生客户端体验

1. 打开 Unreal Engine 5.7，双击打开目录下的 `毕设1/毕设1.uproject`。
2. 打开主关卡：`Content/BISHE.umap`。
3. **自动化装配**：工程配置了启动钩子，会自动执行 `Content/Python/init_unreal.py`，调用 `setup_vr_scene.py` 自动完成材质指定、复杂碰撞体开启、VR 初始点校准及体积云高度修正。
4. **VR 运行**：连接 VR 头显串流后，点击播放下拉按钮选择 **「VR 预览 (VR Preview)」**，即可置身于仙阙台前，通过 VR 手柄射线传送漫游全场。
